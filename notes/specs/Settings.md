# Settings

## Theme

The light and dark themes are one palette at two lightnesses. A setting follows the desktop's
theme, changing with it while the app runs.

## Tab

A dock tab with the theme (light, dark, or follow the desktop, naming what the desktop
prefers now) and, per font, a family box and a size stepper with a preview in that font. An
override is told from the default three ways: the label's colour, real text instead of a dim
placeholder, and a Clear button only where there is something to clear. The placeholder shows
the value that would be used. Settings apply live, and line heights follow their font.

## Fonts

By default the interface and fixed-width fonts are the desktop's: KDE's or Gnome's on Linux,
with Gnome's text scaling applied to the size; Windows' interface font, with Consolas as the
fixed-width one.
